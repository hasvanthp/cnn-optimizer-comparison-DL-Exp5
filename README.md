# CNN Optimizer Comparison

## Overview

An experimental comparison of seven optimization algorithms for
Convolutional Neural Network (CNN) image classification using MNIST.

## Objectives

- Implement a common CNN architecture.
- Train the CNN using seven optimization algorithms.
- Compare classification performance and computational efficiency.
- Generate evaluation metrics, comparison tables, and graphs.

## Optimization Algorithms

1. SGD
2. SGD with Momentum
3. Adagrad
4. RMSprop
5. Adam
6. AdamW
7. Nadam

## Dataset

- Dataset: MNIST
- Image dimensions: 28 x 28 x 1
- Classes: 10 handwritten digits
- Training samples: 54,000
- Validation samples: 6,000
- Test samples: 10,000

## Experimental Configuration

- Batch size: 128
- Epochs: 10
- Framework: TensorFlow/Keras

## Evaluation Metrics

- Test accuracy
- Test loss
- Precision
- Recall
- F1-score
- Training time

## Technology Stack

Python, TensorFlow, NumPy, Pandas, Scikit-learn,
Matplotlib, pytest, Git, GitHub, and Google Colab.

## Execution

The experiment is designed to run in Google Colab.
A compatible GPU is recommended but not required.

## Results

Experimental results and comparison graphs will be added
after the training experiments are completed.
